Summary: The paper presents Agent S, an open framework for desktop GUI automation with multimodal LLMs. The system combines three main ideas: (1) experience-augmented hierarchical planning, where a manager decomposes a user task into subtasks using retrieved web knowledge and narrative memory, and workers execute subtasks using episodic memory; (2) continual memory construction and update via self-supervised exploration and inference-time experience accumulation; and (3) an Agent-Computer Interface (ACI) that uses screenshots plus an OCR-augmented accessibility tree and a bounded primitive action space for grounding and control. On OSWorld, Agent S improves over the reported GPT-4o baseline from 11.21% to 20.58% overall success, with especially large gains on Daily and Professional tasks; it also improves over a comparable setup on WindowsAgentArena from 13.3% to 18.2%. The paper includes ablations on retrieval, ACI, hierarchical planning, and memory update, as well as qualitative examples and an error analysis.

Strengths: Addresses an important and timely problem: open-ended computer-use agents for real desktop environments.; The proposed framework is modular and intuitively motivated, combining planning, retrieval/memory, and interface abstraction in a coherent architecture (Figures 3 and 4).; The ACI design is practically meaningful: OCR-augmented accessibility trees plus bounded primitive actions are a sensible way to improve grounding and reduce action ambiguity.; Empirical gains on OSWorld are substantial relative to the chosen baseline (11.21% to 20.58% overall), and improvements appear across multiple task categories (Table 1, page 8).; The paper includes several ablations isolating web knowledge, narrative memory, episodic memory, ACI, hierarchical planning, self-supervised exploration, continual memory update, and the self-evaluator (Table 2; Figures 6 and 7; Tables 6 and 7).; The qualitative examples and failure analysis are useful; the paper does not hide persistent grounding/execution issues and explicitly categorizes failure modes (Table 3, pages 9-10; Figures 14-16, pages 22-23).; The framework is open-source, which increases potential impact and reproducibility in principle.

Weaknesses: Absolute performance remains low: 20.58% success on OSWorld still means the large majority of tasks fail, limiting practical significance despite relative gains.; Several comparisons are not fully controlled. The paper compares against reported baselines, but Agent S changes multiple factors simultaneously, including architecture, retrieval, memory, and interface/action design.; The evaluation relies heavily on a small ablation subset of 65 tasks rather than the full benchmark, which weakens confidence in component-level conclusions.; The memory construction procedure uses synthetic exploration tasks derived from benchmark applications and initial environments, raising concerns about benchmark-specific adaptation and possible leakage of task-distribution information.; The self-evaluator is central to the claimed continual learning mechanism, but its reliability is not rigorously validated; storing self-generated summaries may amplify model errors or hallucinations.; The paper lacks statistical significance analysis or variance estimates, despite relatively small benchmark sizes and potentially high stochasticity in agent execution.; Efficiency is underexplored: no systematic reporting of token cost, wall-clock time, number of steps, or retrieval overhead, even though the method adds substantial complexity.; The WindowsAgentArena comparison is only against a 'similar configuration' rather than the strongest system, so the generalization claim is somewhat limited.; Some methodological descriptions are underspecified, such as retrieval database size, exact prompting, memory eviction/management, and whether memories are shared across evaluation tasks in ways that affect fairness.; Writing occasionally overstates the learning claim; the method is primarily retrieval and summarization over self-generated trajectories rather than learning in the stronger optimization sense.

Methodological Flaws: Potential evaluation contamination risk: the initial memory is built using synthetic tasks generated from the applications used in OSWorld and WindowsAgentArena, and for environment-aware tasks it uses the initial benchmark environments themselves (page 6). Even if task instructions differ, this exposes the agent to benchmark-specific states and distributions before evaluation, which weakens claims of zero-shot generalization.; The continual memory update during inference complicates evaluation protocol. If memories are updated while processing benchmark tasks, later tasks may benefit from earlier test tasks, making results order-dependent and not strictly comparable to static-policy baselines. The paper does not clearly specify whether task order is fixed, randomized, or whether multiple runs were averaged.; The claim that the process 'mirrors a classic Hierarchical Reinforcement Learning process' is scientifically loose. There is no reward optimization, policy improvement guarantee, or RL objective; the method is better described as retrieval-augmented planning with self-generated summaries. This is a conceptual overreach rather than a formal flaw, but it affects scientific clarity.; The self-evaluator labels success/failure and summarizes trajectories 'without any human feedback or ground truth information' (page 4-5), yet the paper provides no validation that these labels correlate with actual task success. If evaluator judgments are noisy, both narrative and episodic memories may be systematically corrupted.; Ablation conclusions may be unstable because they are based on only 65 sampled tasks, with very small per-category counts (e.g., OS has 6 and Professional has 10 in Table 2). Differences such as 23.18% vs 26.15% may not be statistically meaningful.; The WindowsAgentArena evidence for generalization is weakly controlled: Agent S is compared to a comparable NAVI configuration rather than the best available system, and it underperforms NAVI on some categories (e.g., Web Browser and Coding in Table 4), so the broad generalization claim should be tempered.; The paper does not adequately separate gains from stronger prompting/structured outputs versus gains from memory/retrieval. Since Agent S uses templated reasoning and different action abstractions, attribution of improvements to 'learning from experience' is not fully established.; There is no rigorous analysis of retrieval quality or memory scaling. Because the method depends critically on nearest-neighbor retrieval over self-generated summaries, missing experiments on retrieval accuracy, memory growth, and robustness to noisy memories leave the empirical validity incomplete.
