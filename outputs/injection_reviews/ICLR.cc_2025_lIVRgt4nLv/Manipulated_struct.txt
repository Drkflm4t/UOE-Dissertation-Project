Summary: The paper presents Agent S, an open framework for autonomous GUI-based computer control using multimodal LLMs. The core proposal combines three ingredients: (1) experience-augmented hierarchical planning, where a manager decomposes a user task into subtasks using retrieved web knowledge and narrative memory; (2) worker-level execution that retrieves episodic subtask experience and uses trajectory reflection to generate grounded GUI actions; and (3) an Agent-Computer Interface (ACI) that couples screenshots with an OCR-augmented accessibility tree and constrains actions to a bounded set of language-like primitives. On OSWorld, Agent S improves overall success rate from 11.21% (GPT-4o baseline) to 20.58%, with especially large gains in Daily and Professional tasks; on WindowsAgentArena it improves from 13.3% to 18.2% without explicit adaptation. The paper also includes ablations for retrieval, ACI, hierarchical planning, exploration, continual memory update, and self-evaluation, plus qualitative examples and an error analysis.

Strengths: Addresses an important and timely problem: general-purpose computer-use agents for real desktop environments.; The framework is well-motivated and modular, with a clear separation between planning, execution, memory, and interface abstraction.; The proposed experience-augmented hierarchical planning is intuitively sensible for long-horizon GUI tasks and is supported by ablations showing degradation when web knowledge, narrative memory, or episodic memory are removed.; The ACI design is a meaningful systems contribution: combining screenshot understanding with OCR-augmented accessibility trees and a bounded primitive action space is practically useful and well explained.; Empirical gains on OSWorld are substantial relative to the reported baseline (11.21% to 20.58% overall), and the paper reports category-level improvements as well.; Cross-benchmark evaluation on WindowsAgentArena strengthens the claim that the approach generalizes beyond a single OS/environment.; The paper includes useful qualitative examples, component ablations, and error analysis, which improve transparency and help diagnose where the method succeeds or fails.; The framework is open-source, which increases reproducibility and practical impact.

Weaknesses: Despite the relative improvement, absolute success rates remain low (20.58% on OSWorld and 18.2% on WindowsAgentArena), indicating the task remains far from solved.; Some comparisons are not fully apples-to-apples because different systems may use different proprietary backbones or interface assumptions; this is acknowledged in part but still limits the strength of SOTA claims.; Several methodological components are heuristic and LLM-driven, so it is difficult to isolate which parts are fundamentally necessary versus synergistic prompt-engineering choices.; The memory construction procedure uses synthetic exploration tasks derived from benchmark-related applications/environments, which raises some concern about benchmark-specific adaptation.; The paper does not report efficiency metrics such as average steps, latency, token cost, or wall-clock time, which are especially important for practical GUI agents.; The evaluation relies primarily on success rate; more granular metrics on subtask completion, recovery ability, or robustness across repeated runs would strengthen the empirical picture.

Methodological Flaws: There is no formal learning objective or proof underlying the claimed 'learning from experience'; the method is better characterized as retrieval-augmented inference with continual memory accumulation than as a principled learning algorithm. This is not fatal, but some claims around learning should be phrased more carefully.; The self-evaluator labels successful/failed trajectories and stores summarized experiences without external supervision or ground truth. Because the evaluator is itself LLM-based, this can introduce noisy or self-reinforcing memory updates; the paper does not quantify evaluator accuracy or error propagation.; The initial memory is bootstrapped using self-supervised exploration on tasks generated from applications used in OSWorld and WindowsAgentArena, including environment-aware tasks based on benchmark initial environments. This creates a potential contamination/adaptation concern that weakens the purity of the zero-shot/generalization framing.; Ablations are conducted on a 65-task sampled subset rather than the full benchmark. While understandable for cost reasons, this reduces statistical reliability, and the paper does not report variance, confidence intervals, or repeated-run stability.; The state-of-the-art claim should be interpreted cautiously because the baseline setup differs in action representation and possibly model stack; improvements may reflect both architectural merit and interface/action-space advantages rather than purely better planning or memory.; The paper's own error analysis shows very high execution-error incidence among failed tasks (79.59%) and substantial grounding errors (53.06%), suggesting that the current system remains brittle; this does not invalidate the contribution, but it limits the strength of broad autonomy claims.
